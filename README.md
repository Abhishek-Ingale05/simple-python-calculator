# Simple Python Calculator 🧮

A beginner-friendly calculator program written in Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Runs repeatedly
* Type `q` to quit
* Handles division by zero
* Handles invalid operations

## How to Run

Make sure Python is installed.

Run:

```bash
python main.py
```

## Operations

| Input      | Operation      |
| ---------- | -------------- |
| `addition` | Addition       |
| `sub`      | Subtraction    |
| `mul`      | Multiplication |
| `div`      | Division       |
| `q`        | Quit           |

## Example

```text
===== Simple Python Calculator =====

Choose an operation:
addition
sub
mul
div
q - Quit

Enter operation: addition
Enter first number: 10
Enter second number: 20
Result: 30
```
